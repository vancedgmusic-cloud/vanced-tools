Peluncur Akun Gmail

Klik satu profil untuk langsung masuk Gmail akun itu — tanpa logout/login ulang.

Cara kerja & batasannya (baca dulu)
  • Tombol di tiap profil membuka Gmail/Drive/dll langsung ke akun tsb pakai mekanisme resmi multi-login Google (URL /u/emailkamu/) — bukan menyimpan password. Syaratnya: akun itu sudah pernah kamu tambahkan lewat foto profil Google → "Tambah akun lain" di browser yang sama. Kalau sudah, klik = langsung masuk, tanpa isi password lagi.
  • Alat ini tidak dan tidak bisa menyimpan 10 password lalu auto-isi form login Google — itu tidak aman, dan otomatisasi form login Google biasanya malah memicu Google mencurigai aktivitas aneh (akun bisa diminta verifikasi ekstra). Jadi fitur itu sengaja tidak ada di sini.
  • Kalau kamu mau pemisahan total seperti profil Chrome di gambar kamu (histori, cookie situs lain, ekstensi beda per akun) — itu fitur Chrome Profile bawaan browser, bukan sesuatu yang bisa dikendalikan dari halaman web. Caranya manual: klik foto profil di pojok kanan atas Chrome → Tambahkan profil lain → ulangi untuk tiap akun, login sekali di masing-masing. Setelah itu kamu tinggal klik profil Chrome-nya langsung.
  • Data 10 profil (nama, email, warna) yang kamu isi di sini cuma tersimpan di localStorage browser kamu sendiri — tidak dikirim ke server manapun. Pakai Ekspor/Impor di bawah untuk backup atau pindah browser.
Data tersimpan lokal di browser ini saja. Maksimum 10 profil.
